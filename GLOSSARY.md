# Daedal vNext Domain Glossary

Daedal preserves project intention, functional/system boundaries, and verifiable progress while Agents work autonomously. This is domain vocabulary, not an implementation specification.

**Project**: Independently governed product or integration effort. Avoid: universal superproject.

**Goal**: Desired outcome with independently assessable acceptance. **Point / Surface** are views of the same Goal: a point in its parent and a surface when decomposed. Avoid: separate point and surface entities.

**Relationship (line)**: Typed, traceable link that explains decomposition, dependency, provision, impact or proof. Avoid: treating every edge as ownership.

**Boundary**: Inherited limits on purpose, capabilities and system responsibility. Avoid: file paths alone.

**Goal Seed**: Authorized starting intention for progressive project discovery.

**Discovery Candidate**: Sourced but not yet accepted observation or inference. **Accepted Knowledge**: Evidence-checked effective map knowledge. Retrieval is not authority.

**Acceptance Contract**: The effective conditions for a Goal to be independently judged complete.

**Revision / Decision Delta**: Traceable effective version, and a proposed change to an existing goal, boundary, or acceptance.

**Live Reference**: Version-identifiable, read-only knowledge from another Project; does not grant ownership or write rights.

**Relevant Subgraph**: Current Goal and necessary ancestors, limits, decisions, neighbors, and proof relationships.

**Work Contract**: Revision-pinned engineering scope/context, not an unlimited bearer token.

**Evidence Receipt**: Verifiable pointer to actual artifact, origin and applicable revision; not an Agent's narrative.

**Independent Verdict**: Assessment against goal, relevant subgraph and real work from a separate verification context.

**Unknown Impact**: Unresolved possible effect; neither PASS nor FAIL.

**Impact Reconciliation**: Re-evaluation of affected work and proof while retaining demonstrated unaffected results.

**Review Profile**: Host-selected, versioned list of mandatory and advisory checks for a Work Contract, chosen from its assessed change risk. Not a new Goal authority.

**Quality Evidence**: Original-report-referenced, revision/contract/profile-bound evidence from an external method (unit, CRAP, mutation, PR, Spec or adversarial review). A tool's green signal is not a Goal verdict.

**Quality Unknown / Block**: Missing or unverified required evidence is Unknown; verified failing required evidence is Block. Neither permits Goal completion.
