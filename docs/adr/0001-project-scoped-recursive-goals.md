# Project-scoped recursive Goals, not a universal ownership graph

Status: accepted product decision, implementation partial (Q2, Q5, Q7–Q10, Q23).

Each integration is an independent Project; a Goal has one structural parent, and the same Goal can be seen as a point or recursively expanded surface. Typed cross-project, versioned references do not transfer ownership or permission. We reject a global superproject DAG because it blurs responsibility and increases coordination beyond a single governable product.
