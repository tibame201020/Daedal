# Goal completion requires independent revision-scoped evidence

Status: accepted product decision, implementation pending (Q6, Q10, Q17–Q19, Q21–Q22, Q24).

An Agent's done assertion, passing unit tests, tracker flag or merged PR is not Goal completion. Knossos must accept authentic evidence pinned to effective Goal/Acceptance revisions and an independent verifier's verdict against the relevant subgraph and actual artifacts. Parent completion requires its own review. This replaces the legacy merge-as-progress shortcut only after explicitly verified migration.
