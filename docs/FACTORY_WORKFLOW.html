The Literate State Machine of Software Production

🏭 Daedal 核心流程藍圖

[!NOTE] 本文不僅是說明文件，也是工廠的即時觀測面板。

🏗️ 核心架構：五大組件協作

工廠由五個角色各司其職，確保專案推進的穩定性。

🗺️ 戰略全景：從意圖到發布

旨在呈現 Daedal 定義下的 Labyrinth 推進過程，與 Knossos 的觀測位置。

🔍 戰術拆解：各階段詳細邏輯

1. Discovery & Design (建構 Labyrinth)

將模糊的自然語言轉化為 Labyrinth 中的軌跡。

2. Ikaros Flight & CI (執行與仲裁)

Ikaros 負責在 Labyrinth 中飛行，CI 負責物理法則仲裁。

Note🏛️ Knossos = 導航，而非動力

Knossos 負責觀測 tracker.json 並在合適時機觸發 Ikaros。Ikaros 則是自主讀取 Labyrinth 結構進行實作。

📊 實時工廠狀態 (Live Status)

Tip觀測中心

以下區塊直接讀取專案內的 tracker.json，提供 Knossos 視角的即時數據。

import json
import os
import glob

tracker_files = glob.glob(".*/tracker.json")
if tracker_files:
    tracker_path = tracker_files[0]
    with open(tracker_path, 'r', encoding='utf-8') as f:
        data = json.load(f)
    print(f"**Current Labyrinth Phase:** {data.get('current_phase', 'N/A')}")
else:
    print("> ⚠️ No active Labyrinth structure found. Factory is idle.")

🛠️ 角色清單 (Ecosystem Roles)

# 角色名稱 系統別名 職責
1 Requirements Analyst Discovery 意圖分類與需求收集
2 Architect Reviewer Design 技術選型與 ADR 產出
3 Factory Iterator Construction 構建 Labyrinth (Specs, Tracker)
4 Task Dispatcher Trigger 產出 Ikaros 飛行指令 (Worker Prompt)
5 Ikaros Worker 符合協議的自服務執行者
6 Knossos Dashboard 專案進度觀測與觸發中心

[!TIP] Literate Strategy: By using .qmd, we ensure that the documentation evolves with the code. Every flight must be recorded.
