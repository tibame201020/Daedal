# Daedal vNext — Accepted Decision Tree

Product baseline from Q1–Q25, 2026-10-22. Product consensus is not implementation evidence.

## Product and autonomy
- Q1=C Agent can evolve the map autonomously.
- Q4 Decision risk: one-way/two-way door, blast radius and evidence confidence. Applicable high-impact irreversible changes require human confirmation.
- Q14=B revision transaction, not silent in-place overwrites.
- Q24=B acceptance change needs independently checked Decision Delta and consistency with parent Goal; an author cannot self-lower and self-certify.

## Project, point, line, surface

- Q7=B: one structural parent per Goal within its Project; other links are references.

- Q9=A: inherited boundaries cannot be bypassed by decomposition.
- Q10=B: independently complete the parent; no child PASS roll-up shortcut.
- Q23=B: Goal Seed plus progressive Agent discovery; unknowns remain explicit.

- Q12=B: semantic drift checks at material transitions; deterministic write checks separate.
- Q13=B: impact-based reconciliation.
- Q16=B: unknown impact blocks reliance on affected PASS, not unconditional project reset.
- Q17=B: only affected Work Contracts become stale.
- Q20=B: discovered observation/inference is not accepted map fact without provenance and revision check.

## Execution and verification
- Q6-A=A: independent review for every Feature, depth proportionate to risk.

- Q18=B: verifier has a separate context, not necessarily a different model vendor.

- Q21=B: evidence receipt references actual origin and revision; do not warehouse private full artifacts.
- Q22=B: verifier examines Goal plus relevant subgraph and real diff/tests.
